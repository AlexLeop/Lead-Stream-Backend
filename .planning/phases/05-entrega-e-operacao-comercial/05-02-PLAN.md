# 05-02 — Outbox Transacional, Conectores Pluggáveis de CRM e Webhooks Universais

1. Modelar motor de Outbox Transacional (`CRMConnection`, `CRMFieldMapping`, `CRMOutboxMessage`, `CRMSyncEvent`) com suporte a múltiplos conectores, garantia 'at-least-once' e deduplicação via `idempotency_key`.
2. Implementar arquitetura de conectores pluggáveis (`BaseCRMConnector`) com conectores nativos para HubSpot, Pipedrive, RD Station, Ploomes, Salesforce e Webhooks Universais com assinatura HMAC-SHA256 (`X-LeadStream-Signature`).
3. Desenvolver motor de mapeamento dinâmico de campos com transformações (`RAW`, `LOWER`, `UPPER`, `DIGITS_ONLY`, `FIRST_NAME`, `LAST_NAME`).
4. Criar rotinas de despacho e tarefas assíncronas Celery com backoff exponencial, tratamento de rate limit HTTP 429 e Dead Letter Queue (DLQ).
5. Expor endpoints de API REST para gestão de conexões, testes ao vivo, mapeamento de campos, sincronização de lotes e cockpit de métricas para o CEO.
